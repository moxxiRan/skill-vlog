状态头不是客套说明。最早一个不是“已冻结”的必需层级就是当前阶段；若“待确认”仍有主题、核心因果、高潮、角色作用或镜头结构问题，停止在当前阶段，不生成下一阶段内容。

所有主题、故事、角色情节、Storyboard、逐镜首帧、逐镜视频提示词、兼容资产和兼容 Seedance 创作都必须先读取 `reference-mechanics.md` 与 `ganamao-six-script-deconstruction.md`；B 模式还读取三份 `b-vlog-*` 参考；涉及三条最新脚本的原文核对、复算或重新提取时，再读取完整 `干嘛猫脚本分析.md`，并确认两份打包副本一致。开始或接续任何正式脚本时还要读取 `production-versioning.md` 与该脚本的 `脚本状态.md`。交付时只迁移机制，不复制具体路线、角色职能、原句或梗。

## 2. 主题讨论与定稿模板

### A. 主题讨论

内部比较 2—3 个方向，但用户需要一个推荐方案时，只展开推荐项，并简要说明未选项为何较弱。此阶段不写完整大纲、逐镜或 Seedance。

```markdown
# 主题讨论｜[工作名]

## 一句话生活愿望
今天想和朋友去／做______。

## 推荐主题
[一句可讨论的主题表述]

## 为什么值得拍
- 活动本身的观看价值：[好笑／好吃／好看／治愈／刺激]

每个观看承诺都必须闭合为：`主动动作 → 环境／物体／身体变化 → 可见结果／收口`。

| 承诺 | 主动动作 | 变化来源 | 可见结果／收口 | 机制差异依据 |
|---|---|---|---|---|
| 承诺1 | [角色主动做什么] | [环境／物体／身体如何改变] | [可见结果或收口] | [与承诺2的动作、变化来源或结果差异] |
| 承诺2 | [角色主动做什么] | [环境／物体／身体如何改变] | [可见结果或收口] | [与承诺1的动作、变化来源或结果差异] |
| 承诺3（必要时） | [角色主动做什么] | [环境／物体／身体如何改变] | [可见结果或收口] | [与已有承诺的真实差异] |

至少保留两个机制不同的承诺；不同地点或不同对象不算不同机制。任一格只能写地点、观看或到达而没有动作、变化和结果时，主题保持讨论中。
- 可自然发生的环境／物体变化：[发动机，不展开完整因果链]
- 蜗牛不可替代点：[壳、触角、黏液、慢速、湿度需求等如何可能改变体验；不是外观装饰]
- 可见结果与收束空间：[只判断是否能形成状态变化，以及是否有处理、继续体验或安静余波空间；不提前写完整高潮]
- 与海洋馆样本的具体差异：[地点组合、对象、互动与高潮]
- 与山水漂流样本的具体差异：[行程、环境发动机、物理后果与收束]
- 与周末聚会／游乐园样本的具体差异：[行程、关系与升级方式]
- 与历史 Vlog 的具体差异：[对照脚本总表中的活动、环境发动机、核心因果、高潮机制、结果和关系变化]

## 主题风险
- [活动是否太普通、依赖台词补故事、角色职责化、场景不可读等]

## 本轮需要确认
- [主题本身、体验方向、规模或必要边界]
```

## 3. 无角色桥段池

选角前在内部填写至少 10 行：

| 现实动作 | 环境或物体变化 | 即时反应 | 可见结果／状态 | 静音可懂 | 短桥段可局部闭环 |
|---|---|---|---|---:|---:|
| 例：抬野餐垫 | 潮水继续靠近 | 集体慢慢后移 | 杯子倾倒、纸袋湿 | 是 | 是 |

事件型候选若不同时满足“可见动作、变化、结果”就删除；纯准备、满足、环境或呼吸段按感官价值与节奏作用判断。短桥段优先在 1—3 镜内闭合，连续高潮可跨更多镜头。**通用蜗牛模式**再从中选择 5—7 个组成体验曲线；B／干嘛猫模式不按 5—7 个桥段配额，先做三条曲线，再归并核心模块、连续故事段，最后拆真实切镜。

以下字段必须在故事曲线和正文前完成。它们用于把用户分析和原始逐切镜中的结构事实迁移到本集，不是复制样本地点、路线、角色职能或笑点。

参考证据：[完整分析稿、原始逐切镜脚本、`references/b-vlog-scene-architecture.md`]
结构变体：[发现驱动／悬念兑现／群像接力／生活任务／完整一日／户外连续任务／自定义]
新鲜感发动机：[换对象／风险升级／换活动与 Reaction／过程细节／同一空间的任务接力／其他]
体验主线／活动链（先不写地点名）：[入口／会合 → 移动或主要任务 → 活动后的变化／恢复 → 另一项自然活动或结束]
主题串联检查：[主题串起整段经历；主要任务只是其中一个核心模块；饭后／任务完成后的后续独立活动或状态；若没有，说明为何主题本身就是单项任务]

## B 主题节奏校准（必填）

| 字段 | 本集填写 | 验收口径 |
|---|---|---|
| 主题承诺（umbrella 主题） | | 这一句话必须覆盖整段经历，而不是只命名一个中段地点或单项菜品 |
| 子主题／主任务 | | 可以后置，但不能冒充 umbrella 主题；写清它与整集主题的关系 |
| 主题承诺首现时间／镜头 | | 通常前 `0:00—0:15`；冷开场可以前 `0:00—0:06` 直接给主题线索 |
| 主题场域建立时间／镜头 | | 普通日常／出游约前 `0:15—0:35`，最迟前 `0:30—0:35` 必须完成，不能拖到 1 分钟 |
| 第一次主题兑现时间／镜头 | | 前 `0:30—0:45` 出现第一项主题动作或小回报；不能只写“等会儿去” |
| 核心记忆事件时间／镜头 | | 可在成片 `51%—79%` 后置；这是高潮／代表性事件，不是主题首次出现 |
| 主题建立→核心事件的任务链 | | 至少列出任务接力、时间推进、关系变化或身体／能量变化，不能用泛化铺垫填空 |
| 主题延迟判定 | | 前 `0:15` 无主题信号、前 `0:35` 无场域、前 `0:45` 无主题动作，或单项任务后半才开始：退回大纲 |

普通出游的允许链条是：`主题 Hook／对象线索 → 短暂会合／移动 → 主题场域 → 第一项主题动作／小回报 → 多任务接力 → 核心记忆事件 → 后果／余波 → 结束`。不能写成“起床／交通／泛化准备持续一分钟，之后才揭示 XXX”。

| 核心模块 | 完整活动／统一目标 | 活动家族与独立观看承诺 | 每模块预计成片时长 | 模块完成状态 | 下一场触发原因 | 时间／关系／能量功能 |
|---|---|---|---:|---|---|---|
| 模块01 | | | | | | |

模块必须先按完整活动归并，再分配地点、连续故事段和真实切镜。同一任务的准备、执行、变化、结果和收拾默认留在一个核心模块；只有任务、对象、时段、参与关系、身体状态或能量功能发生结构性变化才另起模块。预计时长来自内容需要和样本校准，不平均分配，也不把 `2:15—2:35／8—11／11—25／46—67` 当硬配额。

### 模块与段落密度复核

- 五条样本约 `15秒` 换一次核心事件；普通连续故事段平均约 `8.5秒`、中位数约 `6.1秒`。这是复核参照，不是强制切镜表。
- 普通核心模块通常 `10—25秒`；重过程模块可 `34—45秒`，但必须在动作、对象、时段、关系、身体或能量上持续换挡。
- 同一任务连续超过 `45秒` 必须写出结构性换挡；超过 `60秒` 默认退回。单一茶楼／早茶写到约 `70秒`，不能靠揭盖、点餐、等待、吃饭、结账等微步骤冒充多个宏观模块。
- 普通连续故事段超过 `15—20秒` 时，补写连续动作的观看价值和内部状态变化；写不出就合并、压缩或切到独立后续活动。

**兼容 Seedance 生成结果验证：**兼容提示词交付时只写 `待验证`。结果可查看后，按 `production-versioning.md` 的固定块在同一兼容组修订记录故事兑现、角色兑现、连续性、生成偏差、用户判断和处理决定；只看片不增加修订号，修改提示词才新建组修订。B 模式逐镜视频素材使用逐镜验收模板，不填本组验证块。

## 12. 分阶段验收门

不同阶段不能混成一个总分。当前阶段的全部硬证据成立，才能提交用户确认；任一缺失就停在当前阶段。

| 阶段 | 必须留下的通过证据 | 失败时回退 |
|---|---|---|
| 主题 | 活动换成人仍值得参加；2—3个不同观看承诺；至少一个蜗牛不可替代点；与海洋馆、山水漂流、周末聚会／游乐园三条样本的具体差异 | 主题 |
| 故事大纲 | 活动满足先成立；B 模式有样本校准表、结构变体／新鲜感发动机、体验主线／活动链、核心模块链与时长预算；短途出游主题串起整段经历，主要任务只是其中一个核心模块，后续有独立活动或状态；单日／跨日有时间／任务／关系三条曲线，非日程型记录适用曲线及替代证据；另有早期小回报、主动回落、核心场景—事件矩阵、核心记忆事件、后果／恢复和 Ending Ceremony；重要任务有目标→过程→变化／Reaction→完成；每段有完成结果或下一场触发；不能用同一任务的微步骤冒充多个宏观模块；通用模式的桥段合同覆盖不同功能、事件型桥段有设置／变化／反应／兑现并自然收束 | 主题或大纲 |
| 角色情节 | 每个保留角色有在场理由和可见选择；同一刺激下至少两种判断；无固定岗位；跨集倾向有证据且不过度重复 | 大纲或角色情节 |
| Storyboard | 每个桥段有兑现镜头；B 模式核心模块→连续故事段→真实切镜映射完整且每段有进入／退出状态与触发；每次真实切镜一行；每镜一个主要动作中心；接触、结果和持续状态可见；全片镜头编号完整 | 角色情节或 Storyboard |
| 逐镜首帧提示词 | 每个 Storyboard 镜头恰好一条独立首帧；四类首帧状态、Anchor、道具、摄影机和环境字段完整；首帧文件与验证状态可追溯 | Storyboard 或首帧 |
| 逐镜视频提示词 | 每条绑定同镜已验证首帧；一镜一主动作；起点、过程、收口、Motion Carrier、4–6秒生成建议和成片裁剪区间明确 | 首帧或视频提示词 |
| 台词分镜组别对应表 | 唯一五列表格；每句有画面或前后文依据；不复述或新增故事；说话者可证；强动作可写 `（无）` | Storyboard 或台词表 |
| 兼容生图资产 | 仅在用户点名兼容分支时逐组判断图片依赖；只列实际需要的资产提示词，无图片依赖的组不建空行；每个资产有独立提示词、来源、规格、复用范围和状态 | 兼容组或资产清单 |
| 兼容 Seedance | 来源 Storyboard、来源首帧／视频提示词、覆盖镜头、必保留事实和组别-资产映射明确；必须资产已验证或本组明确为待资产验证；每组自包含；不删除核心触发和结果；不提前后果 | Storyboard、逐镜产物或兼容资产清单 |

红线：第三方风险未标注、强塞限定角色、为限定角色拖改活动时段、依赖案件结构、主要事件只能靠台词解释、依据动作库存先选故事、成组照搬参考作品，只替换天气／地点／道具而保留同一因果链，未做原始样本校准就从问题稿反推规则，或把同一任务／活动家族的微步骤拆成多个核心模块来填满起承转合。

## 13. 评审话术

审稿时先说结构问题，不先改台词：

```markdown
最早失效步骤：[生活愿望／活动选择／桥段池／体验曲线／选角／制作适配]
证据：[指出具体桥段为什么静音不成立、角色在执行什么职责、后果为何不可见]
保留：[仍有价值的活动或画面]
删除：[任务、解释、彩蛋或世界观]
重做方向：[从哪一步重新生成]
```
