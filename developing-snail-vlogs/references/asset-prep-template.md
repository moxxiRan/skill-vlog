## 边界与依赖

“生图资产清单与提示词”是 Storyboard 冻结后、用户明确需要兼容 Seedance 或复用固定图像时的按组制作准备交付，不是新的故事创作阶段，也不是 B 模式逐镜首帧产物。B 模式中**每个真实镜头都必须有首帧提示词**，不能用 `A-FRAME` 是否需要来替代；本规范只回答两件事：

1. 有实际图片依赖的视频生成组在交给视频模型前需要哪些可预先生成或复用的图像资产；
2. 每个唯一资产应使用什么生图提示词、参考来源、规格和版本。

它不写正式台词，不替代 Seedance 视频提示词，也不把镜头动作、剪辑、镜头运动或角色关系重新创作一遍。资产提示词描述可复用的图像对象；镜头中的时间、动作、焦距、景别和切镜仍只写在逐镜视觉与 Seedance 产物中。

依赖顺序固定为：

```text
Storyboard-修订___（已冻结）
        ├─ B模式逐镜首帧提示词 → 首帧验证 → 逐镜视频提示词
        ├─ 台词分镜组别对应表
        └─ 兼容生图资产清单 → 兼容 Seedance（引用资产清单和组别-资产映射）
```

## 资产判定

### 必须纳入清单

- 角色参考图中不存在、但必须跨镜保持一致的外观变体、服装、持有物或身体状态；
- 视频模型难以稳定复现的关键道具、结构、文字外的标志性图形、机关或可比较的物体状态；
- 需要作为背景或空间锚点复用的场景板、环境结构、固定地标或材质；
- 需要预先确定形状、颜色、透明度、纹理或方向的特效、材质和环境元素；
- 兼容 Seedance 场景明确需要额外首帧、尾帧或构图参考时，才按冻结机位、焦距、景别、正式角色名和单一时刻的角色动作关系生成镜头关键帧；这不能替代 B 模式每镜首帧；
- 用户明确要求先生成参考图的对象。

### 不应单独生图

- 普通角色身份已经由 `cast-policy.md` 的现有参考图锁定，且本组不需要新外观变体；若本组还有其他图片资产，只在资产提示词中引用该角色参考图，不重复生成 `A-CHAR`；若本组没有其他图片依赖，则直接省略该组；
- 只存在于动作过程中的瞬时姿态、位移、碰撞或反应，默认属于 Storyboard 和逐镜视频提示词；只有兼容分支明确需要额外静态首帧／尾帧参考时，才建立可选的 `A-FRAME`，并且一张图只能锁定一个镜头中的一个静态时刻和一个构图；
- 为了填满表格而增加的装饰物、背景角色、额外路线或故事结果；
- 台词、字幕、画面文字或口型同步内容。

仅在兼容 Seedance 分支中按视频组判断是否存在必须预先生成或复用的图片资产；正式交付只列出确实需要资产提示词的组。没有图片依赖的组直接省略，不建立“无需额外生图”空行，也不把每个镜头强制拆成资产条目。B 模式首帧表仍必须逐镜覆盖全部 Storyboard 镜头。资产类型按需出现：没有使用的 `A-CHAR`、`A-SCENE`、`A-PROP`、`A-FX` 或 `A-FRAME` 不建立 ID、不填空行。

## 资产编号与状态

资产 ID 在同一条 Vlog 内保持稳定，修订号独立递增：

```text
A-CHAR-001  角色外观变体或角色专用参考
A-SCENE-001 场景板或可复用环境
A-PROP-001 关键道具
A-FX-001   特效、材质或环境元素
A-FRAME-001 镜头首帧、尾帧或单构图参考图
```

同一资产用于多个视频组时只建一行，在“适用视频组”列列出全部组；只有设计事实不同，才建立新的资产 ID。需要时在“特殊关联镜头”列补充单镜范围。`A-FRAME` 只在确有首帧／尾帧需求时建立，且默认只关联一个全片镜头，因为它锁定的是该镜头的一个构图。资产清单文件使用自己的 `修订NNN`；表内“当前修订”和生成文件名记录单个资产的修订。Seedance 必须引用 `资产ID@修订＋文件地址`，不能只写资产 ID。资产文件和提示词文件不能用 `V1.x` 互相猜测来源。

资产状态：

| 状态 | 含义 |
|---|---|
| 未开始 | 已识别资产，但尚未写完整提示词 |
| 提示词待确认 | 提示词完整，等待用户确认或补充输入 |
| 待生成 | 提示词和规格已冻结，可执行生图 |
| 待验证 | 已有生成文件，尚未核对身份、空间、状态和可复用性 |
| 已验证 | 生成文件通过检查，可被 Seedance 引用 |
| 有偏差 | 文件可查看但与资产契约不一致，需要重生或改写 |
| 已失效／已取代 | 上游逐镜或新资产修订使其不能继续作为当前依据 |

## 正式产物模板

正式文件使用 `production-versioning.md` 的权威产物头，并增加以下专属字段：

```markdown
> 产物：生图资产清单与提示词
> 来源 Storyboard：[Storyboard-修订___]
> 覆盖视频组：[第__组、第__组；仅列出有资产提示词的组]
> 关联 Seedance：[第__组、第__组，或未开始]
> 资产结果状态：[未生成／待验证／部分验证／已验证／有偏差]
```

### 资产清单

| 资产 ID | 类型 | 资产名称 | 适用视频组 | 特殊关联镜头（可选） | 首次使用 | 复用范围 | 来源／参考图 | 必须／可选 | 生图提示词 | 负面约束 | 输出规格 | 状态 | 当前修订 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| A-SCENE-001 | 场景 | [名称] | 第1组 | 无 | 第1组 | 第1—2组 | [场景模块／参考图地址] | 必须 | [完整提示词] | [不要出现的元素] | [尺寸／比例／透明背景等] | 待生成 | 修订001 |

### 按组资产提示词索引（仅列出有资产需求的组）

| 视频组 | 覆盖全片镜头 | 本组实际需要的资产 ID | 资产用途与必须保持的事实 |
|---|---|---|---|
| 第1组 | 镜头001—003 | A-SCENE-001、A-PROP-001 | [本组背景地标、道具形状／状态] |

最小交付示例：如果第1组只需要固定场景和一个关键道具，正式清单只出现 `A-SCENE-001`、`A-PROP-001` 及其提示词；不补写 `A-CHAR`、`A-FX` 或 `A-FRAME`。如果第2组完全复用模型可稳定生成的环境和现有角色参考图，则第2组在资产提示词清单中不出现；只有它依赖前组自制场景或道具时，才在索引中重复引用对应资产 ID。

内部验收仍要逐组核对，确认没有漏掉需要图片锚点的组；但正式清单只保留有资产需求的组。只要某组依赖某个自制资产，即使该资产已在前组生成或出现，也要在该组索引中重复列出相同资产 ID。只有 `A-FRAME` 或其他明确单镜资产才在“特殊关联镜头”中补镜头号；按组索引不能新增逐镜视觉没有的角色、道具、环境变化或故事结果。

## 生图提示词写法

每个资产的提示词必须是**资产级、可独立执行，并在适用时可复用**的描述，不得把多个资产合并成一张无法拆分的拼贴图，不新增故事、动作或台词事实。涉及 B 模式首帧或兼容关键帧的人类环境元素时，只允许出现脖子以下的真人身体部位，禁止真人人脸、头部和面部轮廓。`A-FRAME` 是例外：它是一个镜头的首帧／尾帧或单构图参考，但仍只能描述一个静态时刻。提示词至少包含：

1. 资产类型和正式名称；
2. 外观、材质、颜色、结构、比例和必须保持的身份特征；
3. 与固定地标、道具或角色的必要空间／接触关系（仅在资产本身需要时写）；
4. 光线、背景、视角、透明度或输出构图要求；
5. 与现有参考图的绑定和不可改变项；
6. 输出规格与复用范围。

推荐格式：

```text
[资产类型]，[正式资产名称]；[稳定外观与结构]；[材质、颜色、比例和状态]；
[必要的空间锚点或接触面]；[光线、背景、视角、透明度和画幅要求]；
与[参考图／角色正式名称]保持[不可改变特征]；不添加[未冻结内容]。
```

分类要求：

- **角色变体**：必须引用正式角色名和已有参考图，写清变体为何需要、哪些身份特征绝不改变；不把一次性动作写成永久外观；
- **场景板**：写空间拓扑、固定地标、材质、光线和可复用视角；不要把某一镜的剪辑或角色动作藏进场景提示词；
- **道具**：写结构、尺寸比例、开合／干湿／松紧／损坏状态和可接触表面；不要用“神秘”“漂亮”等词替代形状与状态；
- **特效／材质**：写形状、方向、边界、透明度、颜色和强度范围；不要提前写只在后续镜头发生的结果；
- **镜头关键帧**：必须写全片镜头号、首帧或尾帧、具体场景位置、成片摄影机方位／光轴、数值焦距、景别、每个可见角色的正式名称、静态位置、朝向、持有物、接触点和动作关系。若包含真人路人，只允许脖子以下部位，不能出现真人人脸；只描述选定瞬间，不写“先／再／随后”、镜头运动、切到特写或第二种构图；下一构图必须建立新的 `A-FRAME` 并绑定对应镜头。

负面约束只禁止会破坏冻结事实的内容，例如角色复制、身份互换、额外文字、错误方向、错误状态、未冻结的灾难或额外角色；不能用负面约束否定本镜必须发生的核心动作。

## 交接与验证

### 交给 Seedance

兼容 Seedance 来源头增加：

```markdown
> 来源生图资产：[生图资产清单与提示词-修订___／本组无资产提示词]
> 来源 B 模式首帧／视频提示词：[逐镜首帧提示词-修订___／逐镜视频提示词-修订___]
> 组别-资产映射：[第1组=A-SCENE-001@修订001、A-PROP-001@修订001；……／本组无资产提示词]
> 镜头-资产映射（仅单镜资产）：[镜头002=A-FRAME-001@修订002；……／无]
> 必须已验证资产：[资产ID@修订＋文件地址；没有则写缺口]
> 资产依赖状态：[本组无资产提示词／待资产验证／已满足]
```

兼容视频净输入只引用组别-资产映射中的资产 ID、资产修订、已生成文件地址或参考图绑定；不把生图提示词、B 模式首帧或视频提示词整段复制进 Seedance，也不允许兼容 Seedance 阶段临时发明资产。

如果本组有必须资产但资产仍为 `未开始`、`提示词待确认`、`待生成`、`待验证` 或 `有偏差`，不交付“已冻结”的最终 Seedance 净输入；Seedance 基础状态保持 `待确认`，专属字段写 `资产依赖状态：待资产验证`，不能标记 `已冻结`。资产依赖状态是专属门槛，不是权威产物状态的新枚举。

### 退回与失效

- 逐镜画面事实、镜头号、组别映射变化：新建资产清单修订，相关组别资产映射和 Seedance 组重新验收；
- 只改资产提示词且不改变冻结画面事实：只递增资产修订，并将引用它的 Seedance 组标为 `待重验`；
- 生成图改变角色身份、场景拓扑、道具状态或故事结果：退回逐镜视觉或更早阶段，不能只换一张图掩盖；
- 资产被取代时保留旧文件和结果记录，不覆盖或删除；当前 Seedance 不得继续引用已失效资产。

## 交付前检查

- [ ] 所有实际需要图片锚点的视频组都已列出资产 ID；无图片依赖的组不建立空行。
- [ ] 每个资产 ID 只有一个当前定义，适用视频组、特殊关联镜头（如有）和复用范围可追溯。
- [ ] 所有必须资产都有独立、完整、不含占位符的生图提示词、负面约束和输出规格。
- [ ] 资产提示词没有新增故事、角色职责、动作结果或镜头切换。
- [ ] 角色、场景、道具和特效提示词没有互相覆盖或把多个独立资产拼成一张图。
- [ ] 只有确有首帧／尾帧需求时才建立 `A-FRAME`；每个 `A-FRAME` 只绑定一个全片镜头和一个静态构图，明确场景、摄影机、数值焦距、景别、正式角色名与动作关系，没有暗含切镜。
- [ ] Seedance 的组别-资产映射与本清单一致；存在单镜资产时，其镜头-资产补充映射也一致；视频净输入没有混入生图提示词。
- [ ] 生成文件地址、资产修订和验证结果已写回版本记录。
