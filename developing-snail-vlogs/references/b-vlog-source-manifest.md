## 3. 证据层级

发生冲突时按以下顺序处理：

1. 用户当前明确要求或冻结决定；
2. 当前权威增强版及可核实逐切镜数据；
3. 本清单登记的执行短版；
4. 旧分析、旧问题稿和历史案例。

样本统计是观察事实与复刻基准，不是所有新视频的硬配额。宏观环境块是为了创作复刻进行的人工归并，不等同于原逐切镜表的章节标签。

## 4. 更新检查

收到新的完整分析或逐切镜源时：

1. 核对文件是否完整；
2. 登记文件名、样本范围、行数、字节数和 SHA-256；
3. 比较选题、主题时机、宏观环境、事件章节、连续故事段和实际切镜口径；
4. 更新完整分析副本；
5. 同步更新两个执行短版与 `SKILL.md` 的统计口径；
6. 运行 Skill 验证与关键词检查，确认不再残留旧版本门。
