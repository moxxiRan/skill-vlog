# 三条故事的结构差异

| 故事 | 核心类型 | 推进动力 | 主要高潮 | 最值得复用的结构 |
|---|---|---|---|---|
| 水族馆一日游 | 旅行观光型 | 新场景、新动物、新互动不断出现 | 海豹互动、游乐设施、烟花 | 环境建立镜头 → 角色观看/互动 → 反应镜头 → 再进入下一个新地点 |
| 漂流旅行 | 冒险故事型 | “开头到底发生了什么”的悬念 + 正式漂流主线 | 巨浪、水花淹没镜头 | 高潮冷开场 → 回到起点 → 日常铺垫 → 再次进入主线 → 兑现开场 |
| 朋友团建＋游乐园 | 朋友团综型 | 固定角色关系、小笑点、反应差异 | 过山车连续反应 | 成员轮流出场 → 集体事件 → 单人反应 → 小笑点 → 快速换场 |

## 统一视觉规律

三条视频真正稳定复用的是摄影规则，而不是场景：

**16:9 横版；超写实毛发与真实动物体型；真实公共空间；GoPro/运动相机质感；约18mm超广角；轻微鱼眼；猫视角低机位；自拍时允许极端贴脸、边缘裁切、主体遮挡；自然曝光或普通环境光；允许构图不完美；不要商业摄影感、电影级布光、精致中心构图、二维卡通化。**

首帧的核心目标不是“漂亮”，而是像**运动相机突然被打开时抓到的一帧现场照片**。
