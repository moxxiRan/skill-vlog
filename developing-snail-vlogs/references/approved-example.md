## 1. 使用方式

本案例用于审查方法和失败诊断，不是新选题的素材库。开发全新主题时，先在不读取本文件的情况下完成活动、桥段池和故事骨架，再用本文件做反刻意检查。

不要复制海边、潮水、野餐垫、慢速逃离、被保护的食物或三次逼近等具体元素，也不要把它们分别换成暴雨、热浪、人群、车辆或其他外力。只迁移更高层的原则：真实活动先行、画面可读、环境参与、后果持续、角色后置。

## 2. 已通过主题

**工作标题：**《和朋友去海边野餐～位置好像坐得太前了》

**生活愿望：**今天天气很好，想和朋友去海边野餐。

**一句话故事：**

> Garden 和朋友在低潮时选了一块看起来完全合理的海边平地；每次玩回来，海水都更近一点。他们每次只往后挪一点，直到真正准备撤退时，才发现蜗牛的速度赶不上涨潮。

**角色：**

- Garden：体验与掌镜锚点。
- Beer、麦当劳蜗、侦探蜗：普通同行朋友，不分配固定人设任务。
- 宝箱吸血鬼蜗：白天不出现。
- Golden：不进入大纲；若美术需要，可在不影响因果的远景中作为可删彩蛋。

## 3. 约 90 秒大纲

> 本节是视觉故事大纲，不是最终台词分镜组别对应表。大纲和逐镜阶段只标出台词机会；逐镜视觉、全片镜头号和视频组别冻结后，所有台词只填入唯一五列表，不另写字幕稿或配音稿。画面承担潮水因果，台词格承担当下观察、朋友接话、判断偏差和冷幽默拍点。四位“普通朋友”仍应在同一事件里表现不同判断方向，例如先护食物、仍惦记饮料、过度乐观或最早注意到湿痕；这些只是当下选择，不应固化为职业任务。

### 0—10 秒：出门集合

阳光进入房间。Garden 拉开窗帘，把毛巾、防晒霜和相机放进包里。下一镜已经在车上；朋友吃零食、看窗外、挤进自拍。

不介绍名字，不解释身份，不让角色表演固定口头禅。

### 10—23 秒：“一线海景”

到达时正在低潮。稳定远景清楚交代大片平整沙滩、远处海岸线与充足空位，使这个位置当时看起来合理。

大家铺垫、撑伞、摆饮料和食物。Garden 环拍；此处标记台词机会：“一线海景。”

### 23—40 秒：先让海边真的好玩

挖沙、堆壳形沙堡、踩浅水、推沙滩球、戴墨镜拍照、回到垫子上吃东西。

过程中偶尔回到同一远景。观众可以看到海在接近，但角色尚未讨论。

### 40—49 秒：第一次反作用

一小股水碰到垫角，并灌满沙堡护城河。离得最近的朋友只把纸袋往里推一点。大家看一眼，继续吃。

不尖叫，不加悬疑音乐。平静反应比解释更好笑。

### 49—61 秒：“已经解决了”

下一次水让空杯子慢慢漂走。Garden 的镜头跟着杯子，有人顺手追回。

大家抬起整张垫子，连食物都不收，只向后移动约一个蜗牛身位，然后重新坐下。稳定远景里，海水显然马上还会到。

### 61—76 秒：认真撤退但没有速度

第三次水到垫边，大家终于收拾：抱饮料、拖野餐篮、扛遮阳伞、抬食物盒。

使用稍长的固定远景，完整显示它们撤退得很认真、很缓慢，而海水持续追上。不要为了“快节奏”把这个画面剪碎。

稍大的浪托起垫子，饮料倾倒。有人下意识把食物盒举高，Garden 的镜头被撞歪。

### 76—86 秒：可见后果

水退下去。大家保持原姿势安静两秒：纸袋湿透、壳上粘沙、一只触角挂着海草、伞倒在旁边，只有被举起的食物还干着。

不追究谁救了食物，不补角色高光。

### 86—98 秒：恢复与收束

下一镜，大家坐在高处木台阶上。湿纸袋摊开晾着，几只蜗牛分享剩下的食物。Garden 擦掉镜头水珠，拍夕阳与合影。

最后回到初始固定远景：原位置已被海覆盖，沙堡只剩一个壳尖。

此处标记收镜台词机会：“下次坐后面一点。”

## 4. 为什么成立

| 机制 | 案例中的执行 |
|---|---|
| 活动本身值得看 | 海边野餐即使换成人也有向往感 |
| 环境而非编剧任务推动 | 潮水自然接近 |
| 观众早半拍发现 | 同一远景连续交代海岸线变化 |
| 三次升级 | 碰垫角 → 杯子漂走 → 整张垫子被托起 |
| 物种只在关键处参与 | 认真撤退时才自然显出蜗牛速度 |
| 画面可静音理解 | 漂杯、搬垫、慢撤、湿纸袋都无需解释 |
| 后果持续 | 沙、海草、湿袋进入恢复段 |
| 高潮后恢复 | 搬到高处继续吃、擦镜头、看夕阳 |
| 无人设展示会 | 朋友按位置和动作参与，不履行固定职责 |
| 无道理总结 | 初始位置被淹的回扣自然完成结尾 |

核心画面不是某角色说了什么，而是：

> 一群蜗牛抬着正在开饭的野餐垫认真逃跑，但潮水仍然追上来。

## 5. 拍法约束

- 到达、第一次碰水、正式撤退和结尾尽量复用同一稳定远景，让变化由画面自己说明。
- 第一次反作用采用低反应，不加案件感、倒计时或悬疑音效。
- 撤退段允许 5—10 秒固定镜头，让“慢”在画面内部发生。
- “一线海景”和“下次坐后面一点”是贯穿前后的两个台词机会，不是另一份台词清单。最终只在五列表的对应镜头行判断角色对话、贴画面短句、VLOG 路标或 `（无）`。
- 不把“湿透”当作猫式落汤笑点；蜗牛的有效后果落在撤退速度、纸袋、食物、沙与海草。
- Golden 若出现，删除后成片必须毫无缺口。

## 6. 不要把案例变成新公式

不得推导为：

- 每集都要有三次同类事故；
- 每集都要让蜗牛因移动慢而失败；
- 每集都要冷开场；
- 每集都要野餐、下雨、湿纸袋或救食物；
- 每集都必须安排固定远景；
- 每集都要夕阳与合影；
- 侦探蜗只能做普通动作，永远不能观察或推理。
- 把潮水换成暴雨或其他移动环境，就算生成了新故事。

同构红线：

> 外力从远处接近 → 蜗牛因移动慢逃不掉 → 大家举高一个物品 → 狼狈但物品得救

这是本案例的具体因果链，不能作为其他主题的默认发动机。

正确迁移的是：真实愿望、可见动作、环境反作用、递进后果、自然恢复和角色后置。若用户明确要求侦探题材，可以写推理，但活动本身仍需成立。

## 7. 已观察到的失败模式

### “最后一根薯条失踪案”与“找雨伞”

失败原因：把案件当故事性；公园与雨夜只是调查背景；侦探、餐饮角色和夜间角色像在执行岗位；笑点依赖台词解释画面；结尾用文字升华友情。

### 无 Skill 基线：夜市合照

基线稿声称“不做介绍卡”，但实际依次安排：

- 侦探追泡沫与番茄酱线索；
- Beer 追开瓶声；
- 麦当劳蜗发明夜市套餐；
- 宝箱蜗随夜灯登场；
- Golden 在反光里压轴。

这仍是角色展示会，只是把介绍卡藏进桥段。若能把每段概括为“某角色因为名字或造型所以做某事”，立即退回无角色桥段池。

### 无 Skill 基线：雨夜忘钥匙

基线稿依靠电话、钥匙遗忘、对白反转与 Golden 挂备用钥匙完成。静音后只有角色站在雨棚聊天；真实雨天体验没有动作价值，麦当劳蜗仍被写成送餐员，Golden 被强行作为解法。

修复这类稿件时，不要增加更多机智对白。重新选择本身值得体验的雨天活动，再寻找雨、积水、伞、湿物品、交通或室内外温差带来的可见变化。
