# Seedance 直投提示词检查清单（B 模式主链与兼容分支）

本清单包含两部分：B 模式的“逐镜首帧 → 逐镜视频提示词 → 逐镜生成验收”主链，以及用户明确要求时的“整组一次提交、组内多个真实切镜”兼容 Seedance 分支。提示词检查与生成结果验证是对应产物修订的证据区块，不新增创作阶段。

## B 模式逐镜主链检查

### 首帧覆盖与验证门

- [ ] Storyboard 已冻结；每次真实剪辑切镜恰好有一行首帧提示词，空镜、Reaction、重复机位和黑场没有被删，同一连续镜头内遮挡／快速运动没有凭感觉新增镜头。
- [ ] 每条首帧提示词是完整、独立、可直接抽卡的图像提示词，不依赖统一前缀、上一镜或组级上下文。
- [ ] 每条首帧明确四类之一：`Action Start`、`Payoff State`、`Ongoing Motion State`、`Stable State`。
- [ ] 每条首帧同时重建角色 Anchor、静态首帧状态、道具关系、摄影机关系、环境可信度、画幅与无文字水印约束。
- [ ] 首帧可有真人路人作为环境／尺度参照，但真人只出现脖子以下部位；没有可见或可辨识的真人人脸、头部、面部轮廓、眼睛、口鼻或侧脸。
- [ ] 首帧版本、**首帧文件地址**、生成／选择记录和状态可追溯；首帧未达到 `已选／已验证` 时，该镜视频提示词保持 `未开始／待确认`。
- [ ] 首帧身份、构图、道具或环境偏差回退首帧修订，不用视频提示词修静态错误。

### 基于首帧的视频提示词

- [ ] 每条视频提示词声明同镜 `来源首帧` 修订和图片地址，一镜一条，不使用上一镜／下一镜最后帧作为输入。
- [ ] 视频正文从已验证首帧开始，只写一个主要动作的 `起点 → 过程 → 收口`，并明确 Motion Carrier 与摄影机运动。
- [ ] 视频提示词不重新设计构图、角色、道具、摄影机，不新增第二镜头、第二主动作、故事事实、对白、口型或自动字幕。
- [ ] 若首帧含真人路人，视频中始终只保留脖子以下部位；没有抬头、转脸、补出脸或生成首帧裁切范围外头部的结果。
- [ ] 不把附件样本描述成已有视频 prompt 语法；视频 prompt 格式按本项目生产契约执行。
- [ ] 单独记录建议生成时长 `4–6 秒` 与预计成片裁剪区间／功能镜长；生成时长不等于成片镜长。

### 逐镜视频结果验收

- [ ] 每个生成文件、任务标识、来源视频提示词修订和稳定可用区间可追溯。
- [ ] 逐镜检查角色身份、主动作、道具关系、运动方向、入／出点、前后语义连续性和成片裁剪区间。
- [ ] 逐镜检查真人元素是否始终无真人人脸；发现静态人脸回退首帧，发现视频补脸或露脸改视频提示词。
- [ ] 结果有偏差时区分首帧错误、视频措辞错误和 Storyboard 因果／镜头边界错误，分别回退；无可查看结果时明确标记 `成片未验证`。

## 兼容 Seedance 分支

以下原有条目只在用户明确要求旧式“一组一次提交”时适用；组级映射和资产门不能阻塞 B 模式主链。

## 上游阶段门

- [ ] 已读取 `reference-mechanics.md` 与三条最新脚本拆解，当前故事遵循其活动承诺、行程骨架、局部闭环、反应差异、高潮闭合与题材适配的收束机制，但没有复制具体路线、角色职能、原句或相同对象加相同落点的笑点。
- [ ] 主题已有用户可追溯的明确确认，且当前提示词没有改变生活愿望、故事范围或排除方向。
- [ ] 故事大纲及其活动亮点、核心因果、高潮闭合、可见结果、题材适配的后果处理／继续体验／安静余波和结尾均已明确冻结。
- [ ] 角色情节稿已冻结；每个保留角色的在场理由、当下选择、动作、反应和朋友关系已有上游依据。
- [ ] Storyboard 事件、镜头编号、动作因果和镜头收口已冻结；本次只把这些镜头转换为兼容组生成语言。
- [ ] 文件头声明所属脚本、来源 Storyboard 修订、来源首帧／视频提示词、覆盖全片镜头、组别映射、当前组修订和状态；存在预生成资产时还声明来源资产清单修订、组别-资产映射、必要时的镜头-资产映射、必须资产及其验证状态；它们与 `脚本状态.md` 一致。
- [ ] 每个全片镜头恰好属于一个视频组；本组组内顺序与台词分镜组别对应表使用同一映射。
- [ ] 用户指定的版本稿、旧稿或已有脚本已经逐层验收，没有用版本名代替缺失的主题／大纲／角色／分镜批准。
- [ ] 本次 Seedance 转换没有新增桥段、改变高潮、补造角色行为、重新分配角色职责或用台词修补画面。
- [ ] 任一上游项不满足时已停止检查并退回最早缺失阶段，没有输出半成品直投块。

## 交付边界

- [ ] 交付对象明确是一组一次生成，而不是要求用户逐镜单独提交。
- [ ] “本组来源契约”写明来源桥段、覆盖镜头、必须保留的触发与结果、允许适配和禁止提前／删除项。
- [ ] 整数 `总时长`、镜头数和每镜相对整数秒都存在；镜头秒数之和等于总时长。
- [ ] 镜头标题没有绝对时间码、小数秒、`00:09—00:14` 或无法计算的模糊时长。
- [ ] 从标题／总时长到“本组禁止”是完整净输入；没有把台词分镜组别对应表、生图资产提示词、分析、备选或待确认项塞进模型块。
- [ ] 没有占位符、`A或B`、`可选`、`希望`等未决写法。

## 生图资产依赖

- [ ] 本兼容组有图片依赖时，在“生图资产清单与提示词”的按组索引中出现一次；无图片依赖时写本组无资产提示词。只有 `A-FRAME` 或其他单镜资产才需要额外核对镜头映射；它们不能代替 B 模式首帧。
- [ ] 来源资产清单与本组来源逐镜使用同一冻结逐镜修订和同一组别映射；资产 ID、适用视频组和复用范围一致，特殊关联镜头（如有）可追溯。
- [ ] 每个必须资产都有唯一 ID、独立生图提示词、参考来源、输出规格、当前修订和生成文件地址；没有用一张拼贴图代替多个独立资产。
- [ ] Seedance 文件使用专属字段 `资产依赖状态：本组无资产提示词／待资产验证／已满足`；基础产物状态仍使用权威状态枚举。
- [ ] 必须资产已经验证身份、场景拓扑、道具状态和可复用范围；尚未验证时基础状态保持 `待确认`，专属字段写 `资产依赖状态：待资产验证`，不能标记 `已冻结`。
- [ ] Seedance 净输入只引用资产 ID、当前修订、文件地址和参考图绑定，没有复制整段生图提示词，也没有临时新增资产。
- [ ] 资产生成结果没有改变冻结角色身份、场景结构、道具状态或故事结果；存在此类偏差时已退回逐镜视觉或更早阶段。
- [ ] 兼容组中的真人路人只出现脖子以下部位；没有头部、真人人脸、面部轮廓、眼睛、口鼻或侧脸；出现人脸时该组不能标记为已验证。

## 镜头与剪辑

- [ ] 每个镜头只包含一个机位、一个景别和一个主要动作中心。
- [ ] 镜头不是“动作摘要”：正文可直接回答场景在哪里、摄影机从哪拍、谁从什么状态开始、动作先后是什么、谁触发谁、最后画面如何结束。
- [ ] 没有在一个镜头内部暗藏换机位、插入特写、跳时、蒙太奇或第二个剪辑切点。
- [ ] 一组并非被机械写成一镜到底；每个切镜都承担建立空间、反应、阻力、发现、比较或结果中的明确功能。
- [ ] 没有机械套用镜头数量上限或最短时长；短镜头动作立刻可读，长镜头变化连续可见。
- [ ] 复杂群像已按信息功能拆分，互不相关的并行动作没有抢同一动作中心。
- [ ] 一个镜头没有两个独立主动动作；一组没有两条需要同时推进的独立因果链，必要时已拆镜／拆组。
- [ ] 真实动作没有被静态状态帧替代；每个动态笑点有可见起因、推进和收口。
- [ ] 镜头开头同时写出具体场景位置、摄影机方位／光轴、固定／手持／跟拍状态、焦段和景别；不只写“侧面”“中景”。
- [ ] 每个镜头都明确回指场景A／B／N中的一个场景模块；多地点没有被压缩成含糊的“门口／入口内侧”。
- [ ] 镜头标题中的稳定／手持、焦段和景别与正文第一句一致。
- [ ] 每个镜头中首次提及的每个出场角色都用参考图绑定的正式名称标出，并重建该镜头开镜位置、朝向、持有物和初始身体状态。
- [ ] 成片摄影机与角色持有的画面内手持相机已明确区分；角色看向、对准或遮挡的是哪一台设备没有歧义。
- [ ] 动作使用“先／再／随后／最后”排列，并写出开始状态、运动过程（方向／距离／次数或可见力度）和结束后保持状态；没有用“连续”或“用力”单独代替动作事实。
- [ ] 每个接触或碰撞都写明接触对象、接触点、运动方向、次数／持续方式和可见结果；没有只写“互动”“产生反应”“安全距离”。
- [ ] 动作中心、关键接触点、触发者和反应者在构图中可见，没有被装置、前景角色或道具遮挡。
- [ ] 多角色有明确主动者和被动／反应者；其他角色的动作由主动作触发，不是各自同时表演。
- [ ] 镜头结尾写明最后状态和收口方式；遮挡转场明确遮挡物、进入方向、完全填满画幅和直接切入下一镜。
- [ ] 没有用“自然、适当、清楚可见、合理、轻轻互动、随后自然退”等不可检验词替代身体、方向、距离、次数或结果。
- [ ] 最终交付中的每个镜头都完整展开，没有保留“同上”“按同一结构”“延续前镜”等摘要或模板占位语。

## 自包含与连续性

- [ ] 兼容组不依赖上一组、下一组、参考视频或“上一组最后一帧”；本组和每个 B 模式镜头首帧都能独立写出角色、道具、环境和摄影机状态。
- [ ] 角色字母、参考图编号、数量、位置、队形、朝向、服装和配饰明确且不互换。
- [ ] 关键道具写明归属及开合、干湿、松紧、掉落、损坏状态；状态转换有唯一首次发生镜头。
- [ ] 固定地标或旧位置可比较角色位移与环境位移；环境前缘、距离和水线不后退、不重置。
- [ ] 若本组存在移动目标或危险来源，组内每个相关镜头都能读出目的地、危险来源和角色运动方向；纯建立、满足、环境或呼吸镜头不强行添加目的地或危险。
- [ ] 结尾状态明确，下一组可以独立重建它，但本组文字没有要求模型读取下一组。

## 空间与摄影机

- [ ] 场景使用独立“场景提示词”模块；存在已验证场景资产时可以引用，但场景图没有替代文字中的空间拓扑、固定地标和方向约束。
- [ ] 方向主要用真实空间拓扑和地标关系定义，而不是只写画面左／右。
- [ ] POV 写清相机所在一侧、光轴方向、应入画和不应入画的对象。
- [ ] 需要时明确禁止朝海、倒退、横走、跨轴和镜像翻转；禁止项与目标方向不冲突。
- [ ] 匹配远景只复用机位和地标，不把“匹配镜头”误写成跨组视频上下文。

## 因果、结果与状态

- [ ] 事件型生成组的局部链条可写成：正常行动 → 环境施力 → 即时反应 → 可见结果；纯建立、满足、环境或呼吸组有明确的感官／节奏功能，不强行添加事故或额外反应。
- [ ] 核心高潮发生在正确镜头；前镜不提前碰撞／掉落，后组不重新生成同一事故。
- [ ] 速度差、距离推进或物件后果有明确视觉标尺，而非只靠解释词。
- [ ] 允许发生的变化和禁止提前发生的后果分别写出；禁止项没有否定核心高潮。
- [ ] 角色没有被卷走、受伤、复制、融合、换壳或新增不具备的肢体，除非故事明确要求且已锁定。
- [ ] 若本组产生物理后果，状态在后续镜头保持并得到处理；若没有物理后果，则不为了通过检查强行添加事故。

## 台词表与声音隔离

- [ ] Seedance 输入没有台词表内容、角色语义对白、真人旁白、自动画面文字、中文文字渲染或口型同步要求。
- [ ] 声音只描述环境声、音乐、物理音效和非语义短促反应声。
- [ ] 五列台词分镜组别对应表独立于模型输入，并与本组共享来源逐镜和 `组别-镜头` 映射。
- [ ] Seedance 转换轮没有创作或改写台词，台词表也没有反向改动画面事实。

## 生成结果验证

没有可查看结果时，本节只记录 `成片未验证`，不得预填通过。结果可查看后逐项填写到同一 Seedance 组修订和 `版本记录.md`：

- [ ] 生成结果地址／标识和来源 Seedance 修订可追溯。
- [ ] **故事兑现**：冻结逐镜要求的核心触发、动作、反应和结果实际可见，没有只靠说明推断。
- [ ] **角色兑现**：冻结角色情节中的选择、差异和朋友关系实际可见，没有身份互换或无依据的新行为。
- [ ] 连续性：角色身份、空间方向、道具归属和持续状态符合来源逐镜。
- [ ] **生成偏差**：逐项记录遗漏、提前、反向、复制、遮挡、动作失败或其他具体偏差。
- [ ] **用户判断**：记录用户对故事趣味、角色鲜活度和是否接受本次结果的原话摘要；没有反馈写无。
- [ ] 处理决定明确：通过／只改本组提示词并新建修订／退回逐镜／退回角色情节／退回大纲。
- [ ] 只有提示词改变才增加本组修订；只看片和记录结论不增加修订号。
- [ ] 全片关键组通过后，已更新 `vlogs/脚本总表.md` 的跨集机制与成片验证索引；相关角色行为已在角色连续性记录中区分 `剧本已冻结` 与 `成片已验证`。
