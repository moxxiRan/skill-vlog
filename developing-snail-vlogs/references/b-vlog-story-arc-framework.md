# B／干嘛猫 Vlog 故事弧工作模型

> 本文件是故事大纲执行短版。版本事实读取 `b-vlog-source-manifest.md`，环境与数量读取 `b-vlog-scene-architecture.md`。不要复制样本地点、路线、角色职能或具体笑点。

## 1. 一句话模型

> **用一个明确生活目的串起完整经历；让 5—8 个宏观环境块承载 8—11 个核心事件章节，以过程、状态变化和朋友 Reaction 推进，最后用 Ending Ceremony 结束。**

这是一套样本校准后的工作模型，不是硬配额。偏离数量时说明内容理由即可。

## 2. 选题判断

### 2.1 五种结构变体

| 变体 | 新鲜感来源 | 适合的故事 |
|---|---|---|
| 发现驱动 | 更换对象、展区、观察角度 | 观光、展览、探索 |
| 悬念兑现 | 风险或困难逐步积累并兑现 | 漂流、挑战、长途体验 |
| 朋友团综 | 活动接力与 Reaction 差异 | 团建、聚会、游乐园 |
| 生活任务 | 完整过程与身体状态 | 早餐、健身、整理、购物 |
| 完整一日／户外链 | 同一空间的任务接力和时段变化 | 露营、海边、野餐、郊游 |

### 2.2 九问

冻结主题前回答：

1. 观众是否愿意亲自经历？
2. 是否有明确生活目的？
3. 是否能拆出可见任务链？
4. 是否至少有两次状态变化？
5. 过程本身是否有感官价值？
6. 蜗牛是否不可替代？
7. 朋友间是否能产生判断差异和共同结果？
8. 是否有一个核心记忆事件？
9. 是否有自然结束信号？

推荐公式：

> 明确生活目的 + 可见任务链 + 两次以上状态变化 + 朋友关系兑现 + 核心记忆事件 + 自然结束信号

只有静态概念、只能靠台词解释、一个笑点硬撑全片、地点与任务状态始终不变、或没有完成状态的题材，默认不采用。

## 3. 先经历、后地点

按以下顺序写大纲：

```text
生活愿望／观看承诺
→ 体验主线／活动链（先不写地点）
→ 宏观环境链
→ 核心事件章节
→ 连续故事段
→ 实际切镜
```

出游题材至少读得出：

> 进入／会合 → 移动或抵达 → 主要活动 → 活动后的变化／恢复 → 后续独立活动或状态 → 返回／结束

主要任务只是完整经历的一部分。短途早茶题材应先成立为短途城市旅行，再安排早茶、饭后活动、移动与结束；不得用头尾交通镜头把 70s 单一进餐伪装成旅行。

同一物理空间可以承载多个事件章节。判断是否另起章节，看任务、对象、时段、参与关系、身体状态或能量功能是否结构性改变，而不是看门牌。

## 4. 主题节奏

分别记录四个节点：

| 节点 | 回答的问题 | 样本观察 | 推荐目标 |
|---|---|---:|---:|
| Hook／主题承诺首现 | 这集大概要看什么？ | 0—15s | 0—10s |
| Establish／场域建立 | 今天实际要做什么？ | 15—35s | 10—30s |
| First Payoff／首次兑现 | 第一项真实动作或小回报发生了吗？ | 30—45s | 20—35s |
| Core Event／核心记忆 | 最值得记住的时刻在哪里？ | 51%—79% | 依故事安排 |

不要把四者合并成“高潮”。冷开场可先给核心活动片段，再回到生活起点；回到起点后仍要尽快重新建立当天目标。

退回条件：

- 前 15s 只有泛化起床、穿戴、集合或交通；
- 普通日常／出游到 30—35s 仍未建立主题场域；
- 前 45s 没有任何主题动作或小回报；
- 标题承诺直到约 1:00 才真正出现；
- Hook 闪现一次后消失到后半段；
- 单项任务后半段才开始，却没有更大的 umbrella 主题覆盖前段。

## 5. 三条曲线

| 曲线 | 典型走向 | 验收证据 |
|---|---|---|
| 时间 | 早晨→白天→午后→黄昏→夜晚 | 光线、环境、装备、活动时段或跨日信号变化 |
| 任务 | 目标→准备→执行→变化／Reaction→完成→恢复／转场 | 每项任务为何开始、怎样完成、留下什么状态 |
| 关系 | 独处／分散→会合→共同经历→集体记忆→告别 | 成员进入、互相影响、共同结果和关系停点 |

三条曲线不平均用力。日常早段偏时间和个人状态，中段偏任务，后段偏共同经历和情绪收束。

非日程完整经历不强行补早晨与夜晚；填写适用曲线，并记录“不适用及替代证据”。单人故事可用身体／自我状态替代关系曲线。

跨日故事在 `Day Boundary / Reset` 重置：时间、身体、装备、关系和当天目标。不能让第二天直接继承前一天的所有状态。

## 6. 一日波形

使用波浪推进：

> 低位生活基线 → 第一次上升 → 早期小回报 → 回落／呼吸 → 第二次任务波 → 中段笑点或小事件 → 再回落 → 核心记忆事件 → 后果／恢复 → 时间收束 → Ending Ceremony

这是功能地图，不是固定拍数。允许合并相邻功能，但不得同时删除：

- 早期小回报；
- 至少一次主动回落；
- 核心记忆事件；
- 核心事件后的结果或余波；
- 结束仪式。

六类标准标签：

| 标签 | 功能 |
|---|---|
| Entry | 生活基线或冷开场 |
| Threshold | 出发、移动、会合、进入活动 |
| Task | 过程任务与生活证明 |
| Payoff | 小回报、完成、高点或核心记忆 |
| Recovery | 后果、恢复、呼吸、时间推进 |
| Ending Ceremony | 明确结束本次经历 |

故事能量与剪辑节奏分开填写。高能量可以用较长广角保留现场，低烈度也可以用快 Reaction；高潮不因重要就自动占最长时长。

## 7. 任务小弧线

每个重要任务至少回答：

> 目标 → 准备／过程 → 变化或 Reaction → 完成结果／持续状态

不要只写“去了／看了／吃了”，也不要只写结果图。重要过程必须留下可见动作证据，结果必须保留至少一个状态镜头。

任务之间至少使用一种连接：

1. 任务完成；
2. 结果产生因果后续；
3. 身体或生活需要改变；
4. 时间门槛；
5. 关系状态改变；
6. 当前对象新鲜度耗尽；
7. 能量方向需要改变。

重要转折优先同时具备因果、时间或关系中的两项。

## 8. 关系与核心记忆

使用“主 Vlogger + 固定朋友圈”，不平均分戏。让角色差异从同一事件下的抢先、犹豫、逞强、跟随、自保、补救或纠偏中出现。

核心记忆事件只选一个主落点，类型可以是：

- 动作高潮；
- 喜剧高潮；
- 完成高潮；
- 关系高潮；
- 情绪高潮。

核心事件需要前置积累、可见兑现和后续痕迹，但不必成为全片最长章节。可以用冷开场提前曝光结果，不能提前消耗完整因果。

## 9. 回落、余波与结束仪式

回落段承担关闭任务、恢复身体、推进时间、改变关系或重置注意力。环境镜头不是装饰：车窗、树冠、溪流、花海、日落、睡觉和星空可分别承担抵达、呼吸、章节转换、跨日重置和时间收束。

高点后保留湿、累、饱、收拾、回程、互看、继续游览或安静环境等状态。没有物理后果时，也要保留关系反应或情绪降速。

Ending Ceremony 回答：

1. 本次经历是否已经结束？
2. 同行者共同经历了什么；单人完成或承受了什么？
3. 关系或自我状态停在哪里？
4. 观众最后带走哪个画面？

日落、烟花、篝火、星空、合影、告别、回家、睡觉和遮镜都可以使用，但不能开启新剧情。

## 10. 大纲生成顺序

1. 写一句 umbrella 主题和 2—3 个可见观看承诺。
2. 选择结构变体与新鲜感发动机。
3. 写不带地点名的体验主线／活动链。
4. 标出 Hook、场域建立、首次兑现和核心记忆事件。
5. 规划宏观环境链和环境转场。
6. 建立核心事件章节，给每章统一目标和完成状态。
7. 将章节拆成连续故事段，标注任务、关系、时段与能量换挡。
8. 补三条曲线、早期小回报、主动回落、核心事件后余波和 Ending Ceremony。
9. 为每次切场写完成结果、下一场触发和连接类型。
10. 运行双时钟、时长和删除测试。

使用 `templates.md` 的主题节奏表、宏观环境链和场景—事件矩阵输出；数量与样本事实以 `b-vlog-scene-architecture.md` 为准。

## 11. 删除测试

对每个环境块、事件章节和连续故事段分别追问：

1. 是否改变了任务、对象、时间、身体、关系或能量状态？
2. 是否完成上一项承诺，或制造下一项期待？
3. 是否推动至少一条曲线？
4. 删除后故事是否仍完全一样？
5. 上一场完成了什么？
6. 为什么下一场现在必须发生？

前四问均答不出时删除、合并或重写。后两问答不出时，切场通常只是机械换地点。

短途出游额外检查：主要任务是否只是完整旅程中的一个核心事件？任务结束后是否还有独立活动、恢复或结束状态？若没有，除非用户明确要求单项任务，否则退回体验主线。
