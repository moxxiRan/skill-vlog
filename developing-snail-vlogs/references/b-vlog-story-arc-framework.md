## 1. 三层创作单位

同一条 B 风格 Vlog 需要区分三种数量和问题：

> **核心模块 → 连续故事段 → 真实切镜**

| 层级 | 创作问题 | 交付阶段 |
|---|---|---|
| 核心场景—事件模块 | 这一集由哪些完整经历组成？ | 故事大纲 |
| 连续故事段 | 任务、时段、地点、关系或能量在哪里发生了状态变化？ | 场景编排 |
| 真实切镜 | 每段经历如何被拆成可见动作、Reaction、结果和呼吸？ | Storyboard |

场景不是单纯的物理地点，而是：

> **地点语义 + 当前任务 + 角色状态 + 能量功能**

同一地点任务改变，可以开启新的故事段；不同地点仍服务同一目的，可以属于同一移动／转场段。

### 1.1 先写经历链，再分配地点

B 的大纲创作顺序不是“选一个地点 → 在里面编排起承转合”，而是：

```text
生活愿望／观看承诺
→ 体验主线／活动链（先不写地点名）
→ 核心活动／经历模块
→ 为模块分配地点语义
→ 连续故事段
→ 真实切镜
```

体验主线要先写清本次经历的阶段、动作对象、状态变化和下一阶段为什么发生。先登记本集的结构变体与新鲜感发动机，再写核心模块链和每模块预计成片时长；不要从问题稿的地点顺序倒推规则。出游或旅行题材至少要读出：

```text
进入／会合 → 移动或抵达 → 主要活动 → 活动后状态／另一项自然活动 → 返回／结束
```

**主题串起整段经历。** 对短途城市旅行，主要任务只是其中一个核心模块；饭后或任务完成后必须有一个有独立观看承诺的**后续独立活动或状态**。例如“去邻城吃早茶”的主题是完成一次短途城市旅行，早茶只是上午的主要任务和第一次满足，不能承包整条视频。只有用户明确要求拍一项单独任务时，才允许由该任务承担全部宏观结构。

移动、进入和活动后阶段不是装饰性片头片尾；它们只有在改变时间、身体、关系、任务或能量状态时才占据模块。反过来，同一消费场所内的点餐、等待、吃饭、结账或同一物件的连续操作，默认是一个活动模块内部的任务小弧线，不得仅靠拆成多行就冒充整集的宏观起伏。

**同一物理空间可以成立**，可以承载多个连续故事段，户外或日常题材也可以在同一空间推进多个任务；但**场所不是故事主角**。判断单地点是否成立，不看地点数量或人为时长比例，而看活动家族是否真的接力：任务、对象、时段、参与关系、身体状态或能量功能发生结构性变化时可以另起模块；若 Hook、回报、主任务、核心事件和 Recovery 都只是同一任务的微步骤，应合并为一个核心模块或退回重做体验主线。不能用头尾交通镜头把单一任务伪装成完整出游。

单地点例外仍然不能把局部操作硬写成传统冲突—升级—高潮。局部起伏必须由任务接力、时间推进、环境／设施状态、关系反应或身体需要产生；如果只是同一对象被重复处理而没有新的状态变化，应合并或结束该模块。这里是样本校准后的结构诊断，不是“必须两个地点／不能超过某个比例”的硬规则。

## 2. 三条嵌套曲线

| 曲线 | 典型走向 | 检查证据 |
|---|---|---|
| 时间 | 早晨 → 白天 → 午后 → 黄昏 → 夜晚 | 光线、环境、装备、活动时段或跨日信号改变 |
| 任务 | 目标 → 准备 → 执行 → 变化／Reaction → 结果 → 休息／转场 | 任务为何开始、如何完成、完成后留下何状态 |
| 关系 | 独处／分散 → 会合 → 共同经历 → 集体记忆 → 告别 | 成员加入、相互影响、共同结果、最后情绪停点 |

三条曲线不平均用力：早晨可以偏时间和个人状态，白天偏任务与事件，中后段偏共同经历，夜晚让行动退场、时间和情绪收束。单日／跨日故事按三条曲线验收；非日程型完整经历只填写适用的曲线，并写“不适用及替代证据”（例如单人故事以自我状态／身体恢复替代关系曲线），不强行补早晨和夜晚。

简写：`时间曲线`负责证明一天经过，`任务曲线`负责证明事情做完，`关系曲线`负责证明共同经历和告别。

## 2.1 主题节奏三段式（不要把主题和高潮混为一谈）

样本分析中的“主题”有三个不同层次，写大纲时必须分别落点：

| 时间点 | 观众获得的信息 | 样本口径 | 大纲字段 |
|---|---|---|---|
| 主题承诺首现（Hook） | 这集大概要看什么对象、关系、目标或环境问题 | 通常 `0:00—0:15`；漂流冷开场在 `0:00—0:06` 直接给漂流风险 | 主题承诺首现时间／镜头 |
| 主题场域建立（Establish） | 画面第一次明确回答“今天要干什么” | 普通出游约 `0:15—0:35`；水族馆约 `0:30.60`、溪边约 `0:27—0:33`；日常篇从第一项生活动作就成立 | 主题场域建立时间／镜头 |
| 第一次主题兑现（First Payoff） | 第一项主题动作已开始并产生小回报 | 一般在前 `0:30—0:45`；抵达后应尽早给真实动作或小满足 | 第一次主题兑现时间／镜头 |

另列：`核心记忆事件／核心高潮时间`。五条样本的代表性核心事件正式展开约在成片 `51%—79%`，这是记忆点的后置，不是主题建立的后置。漂流可以先冷开场，再回到集合和酒店；游乐园可以在跨日第二天展开，但“朋友团建”从首镜已经成立。若主题只写“健身”或“吃早茶”，却到后半段才开始该单项任务，必须前置第一动作或扩大为“完整一天／短途旅行”等 umbrella 主题。

### 主题节奏硬门

- 前 `0:15` 至少有主题对象、主题关系、目标或可辨识环境信号；不能只有无主题的起床、穿戴、集合和交通。
- 普通单日／旅行题材最迟约前 `0:30—0:35` 建立主题场域，前 `0:45` 出现第一项主题动作或小回报；冷开场可在 `0:00—0:06` 先给主题，但随后 `0:10—0:30` 必须回到起点并再次建立当天主题。
- 主题只在 Hook 闪现、之后消失到高潮才回来，视为主题断线；用台词“等会儿去”不能替代画面中的建立和兑现。
- “主题首现／主题建立／第一次主题兑现／核心记忆事件”四个字段缺一不可；不能用“核心事件约在 51%—79%”为前一分钟空泛铺垫辩护。

## 3. 一日波形

```text
低位基线
  → 第一次上升
  → 早期小回报
  → 回落／呼吸
  → 第二次上升
  → 中段笑点或小事件
  → 再次回落
  → 中后段核心记忆事件
  → 后果／恢复／余波
  → 夜晚结束仪式
```

这是一张功能地图，不是固定八拍。Entry／Hook 可以是日常基线、高潮冷开场或成员入场快剪；冷开场仍要尽快补回“这一天从哪里开始”的基线。主高潮可以缺席或与其他阶段合并，但每集要指定一个最能代表本次经历的核心记忆事件，类型可为：动作、喜剧、完成、关系或情绪。

故事能量与剪辑节奏是两个字段（故事能量和剪辑节奏必须分开记录）。**故事能量不等于剪辑速度**：高能量不必快切，低烈度也可以用快 Reaction；操作过程可以被拆碎，状态、环境和关系余波可以停留。过程任务可以比动作高潮更长，因为过程负责证明“真的做过”。

六类功能单元可作为矩阵标签：`Entry / 生活基线`、`Threshold / 出发与会合`、`Task / 过程任务`、`Payoff / 高点与核心记忆`、`Recovery / 回落与余波`、`Ending Ceremony / 结束仪式`。它们是功能，不是固定地点或时长。

## 4. 任务小弧线

**单个任务本身也是一条小故事。** 每个重要任务至少回答：

```text
目标 → 准备／过程 → 变化或 Reaction → 完成结果／持续状态
```

对外模板统一压缩为：`目标 → 准备／过程 → 变化／Reaction → 完成`。

不要求每个节点独立成镜，但不能只写“去了、看了、吃了”或只给结果图片。任务之间至少有一种连接：

- 任务完成；
- 结果产生因果后续；
- 身体或生活需要改变；
- 时间门槛出现；
- 关系状态改变；
- 当前对象的新鲜度耗尽；
- 需要改变能量方向。

**七类有效切场动因**：任务完成、结果产生因果后续、身体／生活需要改变、时间门槛出现、关系状态改变、当前对象新鲜度耗尽、需要改变能量方向。每次切场至少说明上一场完成了什么，或上一场制造了下一场为什么必须发生的原因。重要转折优先同时具备因果、时间、关系中的两种连接。

## 4.1 样本密度与单模块时长校准

五条约 `2:15—2:35` 样本的核心模块平均约 `15秒` 换挡；普通连续故事段平均约 `8.5秒`、中位数约 `6.1秒`。这不是硬配额，而是检查“是否把一项任务写得过满”的参照：普通核心模块多为 `10—25秒`，重过程任务可到 `34—45秒`，前提是内部持续发生新的动作、对象、时段、参与关系、身体状态或能量变化。

| 复核信号 | 处理 |
|---|---|
| 连续故事段超过 `15—20秒` | 写出这段内部连续动作的观看价值和状态变化；写不出就合并、压缩或切到独立任务 |
| 同一任务连续超过 `45秒` | 必须标注结构性换挡和新鲜感来源；没有就退回活动链 |
| 同一任务连续超过 `60秒` | 默认退回重做；不能用点餐、等待、揭盖、处理菜品、吃饭、结账等微步骤填充宏观波形 |
| 一顿饭／单一消费场所约 `70秒` | 判定为过量案例，除非用户明确把单项任务作为整集主题且内部确有独立状态链 |

样本对照：健身主体约 `45秒`，露营备餐—烧烤—吃饭—收拾约 `34.24秒`；两者都持续更换动作和身体／关系状态。不能把“同一地点”当成问题，也不能把“同一任务的微动作”伪装成多个核心模块。

## 5. 核心记忆、余波与结尾

核心记忆事件应有前置积累、可见兑现和后续痕迹；它可以很短，不必成为全片最长任务。高点后保留湿、累、饱、收拾、回程、互看、继续游览或安静环境等后果／恢复／余波，把刺激转成生活经验。

`Ending Ceremony` 不是新剧情，而是主动结束本次经历。它可以是日落、烟花、篝火、星空、合影、成员告别、回家、睡觉或遮镜，并应回答：

1. 本次经历结束了吗？若是单日故事，再回答“这一天结束了吗”。
2. 有同行者时，大家共同经历了什么；单人时，自己完成或承受了什么？
3. 关系或自我状态停在哪个情绪？
4. 观众最后带走哪一个画面？

跨日旅行在 `Day Boundary / Reset` 处明确重置时间、身体、装备、关系和任务目标，再开始下一天的局部波形。

## 6. B 样本容量参考

五条样本归纳出的复刻参考约为：`2:15–2:35`、`8–11` 个核心模块、`11–25` 个连续故事段、`46–67` 个实际切镜。不同变体的新鲜感来源不同：观光型换对象，群像型换活动与 Reaction，日常型把过程拍细，户外型在同一空间推进连续任务，冒险型依靠风险升级与后果。不能把这些数字当成换地点配额。

## 7. 大纲删除测试

对每个段落追问：

- 是否改变了角色、任务、关系或时间状态？
- 是否完成上一项承诺，或提出下一项期待？
- 推动了时间、任务、关系哪一条曲线？
- 删除后故事是否仍完全一样？

短途出游再追问：主题是否串起整段经历？主要任务是否只是其中一个核心模块？饭后或任务完成后是否有后续独立活动或状态？若答案为否，除非用户明确要求单项任务，否则退回体验主线。

四问都答不出来时，删除、合并或重写该段。
